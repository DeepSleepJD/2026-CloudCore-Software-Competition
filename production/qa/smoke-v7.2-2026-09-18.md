# v7.2 查询任务纠错与部分答案验证

## 本版修复

- 查询工具读取 HTTP 错误响应正文及 WWW-Authenticate 提示，保留 HTTP 状态和发生错误的阶段。业务码错误、数据路径错误也带上真实响应结构与样本，供模型纠正文档中已过时的认证、参数和字段。
- 响应摘录最多 3000 字符；字典最多展示 16 个键、数组最多展示两条样本，明确标注不是完整数据。HTTP 错误正文最多读取 16KiB；不把请求头或请求参数额外放进诊断。
- query 仅在分页证明完整后逐项计算答案。单个字段失败不再删除其他已算出的字段；报告包含 field_errors 和诊断。部分答案先提交，若任务仍在进行，则把已计算字段和失败原因保留给模型继续修正。
- 所有字段都失败时不提交空对象。认证失败、业务错误、漏页、后续页失败时仍不提交任何伪造统计。跨任务清理诊断及字段状态。
- 修复范围是本项目的 query 工具及其回合衔接。通用 command/skill 内部的查询仍由模型编写，不承诺自动修复任意脚本或保证任务全对；字段算出也不等于统计语义已被裁判确认。

## 本机验证：PASS

- 完整测试 141 项通过，34.696 秒。
- 新增 10 项测试，使用真实本地 HTTP 服务、实际沙盒辅助代码和固定模型回复，覆盖 HTTP 错误正文/认证头、业务错误参数提示、非 JSON 有界摘录、结构变更、后续页失败、字段独立计算、非有限值、连续纠错、部分答案补全、空结果防提交和跨任务重置。
- 连续纠错测试从第 9 回合领取，在第 17 回合提交：401 提示认证方式→修改认证→400 提示 location→修改参数→取得两页→提交 count=2。共四次 HTTP 请求，满足测试设置的 15 回合任务预算。
- 部分答案测试先提交 count=2，收到部分错误反馈后按真实数据的 year 字段修正排序，随后提交 count=2 与 oldest=B；没有为未知字段填入占位答案。
- 12 项变异检查全部检出；新增检查分别故意隐藏 API 错误正文、恢复“一字段失败就丢弃全部结果”，对应测试均失败。
- 既有修复题验收、查询分页、任务文件定位、部署包解压后真实 HTTP 服务、战斗、经济和送修测试保留并通过；git diff --check 通过。

测试没有调用真实 LLM 或正式比赛接口；固定模型回复验证的是纠错信息与动作的传递，不是模型在实战中必然理解这些信息。已知本场缺少原始任务交互日志，因此不将本版验证表述为已复现或解决所有实战失败。
