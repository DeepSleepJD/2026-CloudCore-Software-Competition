## 目标与改动

本版针对旧版两火箭加一加特林配置，以及回放中后期经济不足、维修物资未及时到位的问题，建立便于继续迭代的三火箭基线。

- 三座火箭共享操作位置，根据冷却轮流发射；左上与右下基地使用镜像布局。
- 开拓者继续通过比赛提供的模型与沙盒做任务，解法确认成功后缓存，不硬编码回放答案。
- 工人保持采矿目标，出售混合矿石时完成本趟交易，减少中途改变目标造成的无效往返。
- 升级券优先送达使用；维修包统计全队存活人物库存，避免重复采购。
- 低血角色优先用药，维修根据墙体最近掉血量提前触发；火箭提高基地附近高攻击力机器人的目标权重。
- 默认关闭未验证的直接 PvP 和召唤令支出，保留旧策略用于后续对照。

## 提交与使用

比赛提交文件：[`artifacts/zk_dev-submit-v3.tar.gz`](../artifacts/zk_dev-submit-v3.tar.gz)。下载文件本体后上传比赛平台，不需要上传整个 Git 仓库压缩包。

压缩包根目录包含 `run.sh`，使用 `bash run.sh <port>` 启动；Python 3.11+，仅标准库，监听 `0.0.0.0`。`run.sh` 已确认使用 LF 换行并有执行权限。

运行代码版本：`29fb71dc2c0bf672fd8b5f23fe90f5164dbfcdb7`，压缩包内 `BUILD.json` 记录该版本。后续交付提交只增加仓库说明与现有压缩包，不改变运行代码。

## 已完成验证

## 尚未验证和下一轮迭代

当前没有官方完整判题器的对战结果，不能以单元测试或历史回放快照证明存活十天、超过对手或保证胜率。镜像建造区域、真实解题成功率与新策略战斗结果需实战确认。

本版尚未实现新闻预测囤矿和自动寻宝。下一轮先收集本版正式回放，对比首夜剩余血量、逐日采矿销售收入、关键墙失守时点和补给到位情况，再确定优先改进项。
