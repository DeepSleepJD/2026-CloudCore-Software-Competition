- 左右两侧各 1300 回合的简化经济推演通过独立动作检查；seed=42 时两侧第一天均建成 3 台火箭台、12 段墙。

- 冠军回放包含 1024 个回合；转换左右两队基地尚存的状态，检查 1115 份决策，均通过本地合法性检查。
- 决策时延在已测样例中远低于接口的 5 秒响应期限；此结果不能保证未知平台负载下的最坏耗时。

推演没有真实机器人 AI、建筑受伤、生存评分；回放验证也没有将新动作替换进原比赛重新演算。
以上结果证明已测范围内的接口、动作约束和资源闭环，**不是“真实对战存活 1300 回合”的证明**。
