# zk_agent v3：回放学习基线

这是一套可迭代的规则策略程序，不是训练得到的神经网络模型。依据 replay.json 中已观察到的三火箭共用炮位、任务启动经济和关键墙维修，建立默认基线。保留 v2 作为对照，原文档与 Demo 未修改。

当前交付分支：`zk_dev`。**请使用 [v3.1 修复提交包](artifacts/CoreGeek.tar.gz)，不要再上传旧的 v3 包。** 新包的顶层目录和入口对齐官方 Demo：`CoreGeek/main3.py`、`CoreGeek/src/agent/`，策略代码位于 `CoreGeek/src/zk_agent/`。详见 [零动作问题修复说明](docs/v3.1-deployment-fix.md)。

## 运行与提交

Python 3.11+，仅标准库。比赛入口：

解压提交包后进入 `CoreGeek`，使用 Demo 同名入口 `python3 main3.py 8080`；比赛环境应将示例端口替换为平台分配的端口。也支持下方脚本入口。源代码仓库直接运行时不需要额外进入 `CoreGeek`。

```bash
bash run.sh 8080
```

默认启用 v3 baseline。HTTP 监听 0.0.0.0，按官方请求格式返回 roleCommandMap、prompt、executeCmd。回放 JSONL 与比赛 HTTP 请求不是同一种结构，不能直接将回放行作为接口请求。

指定参数：

```bash
bash run.sh 8080 --config config.example.json
```

将配置中的 profile 改为 legacy 可运行旧策略；旧版参数和行为见 README-v2.md。需要完整复现 v2 时，还应使用旧文档给出的两炮、混合炮种和六段墙参数。

## 本版落实的策略

- 初始 75 金币建三座一级火箭；根据实际金币逐步建造，不预支尚未获得的任务奖金。可把 initial_towers 改为 2 测试保守开局。
- 右下采用回放中的三炮相对位置，左上围绕基地中心旋转 180 度。三个炮台可共享一个操作位；自定义布局不能共用时退回分组操作。
- 白天优先让开拓者做任务，工人安排防守位置；傍晚可由能及时赶回的开拓者接班。夜间保持炮手稳定，按炮台真实冷却轮射，不要求另两人整晚守炮。
- 默认九段面向来敌方向的墙，优先修受压正面，保留出入路径。右下布局来源于本次回放，镜像和其他地图建造合法性仍需要官方验证；失败位置会避让。
- 工人记住当前矿点，直到矿点消失、不可达、采集失败或工作目标改变。开始卖矿后，继续清空本趟不同矿种，不因低于出售批量折返。
- 非炮手可夜间采矿和运送，路线避开可见机器人的三格攻击范围；此避险按当前机器人位置判断，不能预测下回合移动。
- 已带升级券优先送去使用。维修包优先送到危险墙；根据上一回合实际掉血量提前修墙，避免固定低血阈值来不及救。
- 全队维修包目标库存两份，计入其他存活角色的背包，防止重复采购；低血角色优先用药，低血采购者优先补药，不先购买昂贵升级券。
- 先将火箭普遍升二级，再逐座升三级。基地掉血时优先基地升级；第三天起补二级基地，第五天起优先三级基地。升级券到位就使用，本基线不冒险压到濒死才升级。
- 火箭瞄准提高正在基地攻击距离内的高攻击力机器人的权重，其次照顾受压关键墙，再考虑普通群体溅射。仍按已计划伤害减少重复攻击浪费。
- 保留沙盒解题与已验证解法缓存；不复制回放中固定答案。默认关闭未经确认的直接 PvP 和召唤令支出。

## 验证证据与限制

新增 12 项基线测试，连同原有 40 项，共 52 项测试。包含真实 HTTP 请求、一个炮手在 60 回合内操控三座火箭各发射 15 次，以及首日基本经济/建造流程。首日小模拟不包含官方建造区域校验、矿点随机刷新、任务奖励和机器人战斗，不用于预测比赛胜率。

回放抽样检查覆盖双方 206 个状态快照，生成 277 条动作；检查角色动作唯一性、攻击操作距离、移动占用及共享金币预算。该检查关闭了回放缺失的任务信息，并将缺失的炮台冷却设为可用状态；不模拟己方新动作对后续历史的影响，不能把历史结局当成新策略结果。

```bash
python -m unittest discover -s tests -v
python tools/check_replay.py /path/to/replay.json --stride 10
```

本版尚未实现新闻预测囤矿、宝藏推理与自动寻宝。原任务解题器需要比赛提供的模型和沙盒，真实题目完成率还没有官方验证。先用本版跑正式环境回放，观察首夜基地血量、后期卖矿收入、关键墙断点和人物有效行动，再决定下一项迭代。

- zk_agent/world.py：地图、路径和动作占用。
- tools/check_replay.py：只读回放快照检查。
